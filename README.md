# StartUp – Empower Your Next Big Idea

A modern, responsive **startup landing page** built using **HTML5**, **CSS3**, and **Bootstrap 5**, designed to help startups showcase their product, pricing, and testimonials with a clean, professional layout.

---

## Live Demo

**https://sherin-startup-landing-page.netlify.app/**

---

## Project Overview

This project is a **one-page startup landing site** that emphasizes clarity, scalability, and user engagement.

It includes:

- A bold **hero section** for first impressions
- Structured **features**, **pricing**, and **testimonials** sections
- A modern **contact form** with floating labels
- A stylish **footer** with social icons and a “Back to Top” button

---

## Features

Fully responsive using **Bootstrap 5**  
Clean and modern design with hover effects  
Floating labels in contact form  
Integrated **Bootstrap Icons**  
Favicon and brand customization support  
Reusable and scalable layout
